# Credit_Card_Financial_Dashboard
Credit Card Weekly Performance Dashboard
📌 Project Overview

This project focuses on building an end-to-end Credit Card Analytics Dashboard that provides weekly insights into revenue, customer behavior, transaction trends and card performance.
The dashboard enables stakeholders to monitor business performance, identify profitable customer segments and make data-driven decisions.

The solution uses MySQL for data storage and Power BI for visualization, following a complete data analytics pipeline from raw CSV files to interactive dashboards.

🎯 Objectives

Build a centralized weekly monitoring system for credit card performance

Track revenue, interest earnings and transaction trends

Segment customers by age and income

Identify high-value and risk customer groups

Support strategic and marketing decision-making

🛠️ Tech Stack

Database: MySQL

Visualization: Power BI

ETL & Transformation: Power Query, DAX

Data Source: CSV files

📂 Dataset Description
Table	Description
cc_detail	Stores credit card transaction and revenue details
cust_detail	Stores customer demographic and profile information
🏗️ Data Pipeline

Prepared raw CSV files

Created structured tables in MySQL

Loaded data using LOAD DATA LOCAL INFILE

Connected MySQL to Power BI

Cleaned and transformed data in Power Query

Built calculated columns, measures and KPIs using DAX

Designed interactive dashboards

📈 Key KPIs & Metrics

Total Revenue

Interest Earned

Transaction Amount & Volume

Customer Satisfaction Score

Revenue by Week

Revenue by Card Category

Customer Segmentation (Age & Income Groups)

Delinquent Account Analysis

📊 Dashboards

Customer Segmentation Dashboard

Transaction & Revenue Performance Dashboard

Both dashboards allow dynamic filtering by week, card category, gender, income group and age group.
